# 反馈聚类

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_dev_04_sk02` |
| 类型 | **`atomic`（原子技能）** |

| 能力族 | — |
| 复杂度 | `S` |
| 阶段 | `P1` |
| 复用度 | 高 |
| 资产形态 | 提示词 + 确定性脚本（纯标准库） |

## 能力描述

对一批用户反馈条目做语义去重与主题聚类：把表达同一诉求的条目归并为一组，输出分组结果（主题、包含条目、频次）、按频次降序的共性洞察，以及每条洞察对应的原始条目编号证据索引。适用于从应用商店评论、客服工单、社群讨论中快速识别集中诉求。配套确定性脚本（关键词聚类口径，纯标准库）可在本地复现聚类结果，产物写入 `out/`（clusters.csv / report.json）。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `items` | array | ✅ | 待处理的条目列表 |

## 输出规格

摘要与聚类

- `clusters`：按共性归并后的分组
- `insights`：从分组中提炼出的共性结论
- `evidence`：每条洞察对应的原始条目编号

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` |
| **ChatGPT** | 新建 GPT → Instructions → 粘贴 `prompt.txt` |

### 方式三：运行确定性脚本（可复现）

1. 进入本技能目录，执行：`python scripts/cluster.py --demo`（内置演示数据）或 `python scripts/cluster.py --input examples/input.json`
2. 脚本按关键词聚类口径归组（条目命中主题关键词即归入，可跨主题；未命中归入「其他 / 未分类」），主题与洞察按频次降序排列
3. 产物写入 `out/`：`clusters.csv`（分组结果）、`report.json`（clusters / insights / evidence 完整结构）

## 边界（不做的事）

- ❌ 编造数据、案例或效果承诺
- ❌ 使用违反《广告法》的极限词
- ❌ 生成诱导好评、刷量、删差评等违规内容
- ❌ 执行或建议任何绕过平台规则的操作
- ❌ 涉及资金操作或代替用户做最终决策
- ❌ 处理超出本职能力范围的请求（应明确说明并建议转其他技能）

## 调用示例

**输入**：

```json
{
  "items": "01「发票拍照识别老是不准，小数点后的金额经常识别错」02「希望发票识别能支持增值税专用发票，现在只能识别普票」03「能不能加个多账本功能？店里和家里开支想分开记」04「多账本刚需，个体户和家用混在一起太乱了」05「求一个账本切换功能，我和合伙人一人一本」06「月报表能不能导出 Excel 给会计看」07「导出功能什么时候上？现在只能截图发会计」08「App 在我的 Huawei Mate 40 上经常闪退，一开发票识别就崩」09「安卓闪退严重，Xiaomi 13 打开报表页面直接退出」10「希望记账界面支持深色模式，晚上记账太刺眼」"
}

```

**输出**：

```markdown
# 反馈聚类 — 执行输出

## 分组结果

| # | 主题 | 包含条目 | 频次 |
|---|---|---|---|
| 1 | 发票识别能力不足（识别不准 / 不支持专票） | 01、02 | 2 |
| 2 | 多账本 / 分账需求 | 03、04、05 | 3 |
| 3 | 月报表导出 Excel | 06、07 | 2 |
| 4 | 安卓端闪退 | 08、09 | 2 |
| 5 | 界面深色模式 | 10 | 1 |

## 共性洞察

1. 「多账本 / 分账」是本批反馈中提及次数最多的主题（3 条），个体户用户分开记录店铺与家庭账目的诉求集中。
2. 「发票识别」相关的批评同时指向准确性与覆盖范围（普票之外希望支持专票），属于功能质量问题与功能范围问题叠加。
3. 「安卓端闪退」集中于发票识别与报表页面两个场景，且与特定机型相关（Huawei Mate 40、Xiaomi 13）。
4. 「报表导出 Excel」两条诉求场景一致：交给会计查看，属于同一使用链条。

## 证据索引

1. 洞察 1 → 条目 03、04、05
2. 洞察 2 → 条目 01、02
3. 洞察 3 → 条目 08、09
4. 洞察 4 → 条目 06、07

—— AI 生成内容，需人工复核 ——


```
