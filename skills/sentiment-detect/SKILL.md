## 输出规格

分类打标

- `labeled`：逐条给出类别与依据
- `distribution`：各类别数量与占比
- `ambiguous`：跨类或无法判定的条目及原因

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` |
| **ChatGPT** | 新建 GPT → Instructions → 粘贴 `prompt.txt` |

## 边界（不做的事）

- ❌ 编造数据、案例或效果承诺
- ❌ 使用违反《广告法》的极限词
- ❌ 生成诱导好评、刷量、删差评等违规内容
- ❌ 执行或建议任何绕过平台规则的操作
- ❌ 涉及资金操作或代替用户做最终决策
- ❌ 处理超出本职能力范围的请求（应明确说明并建议转其他技能）

**输入**：


**输出**：

```markdown
# 情绪识别 — 执行输出

## 分类结果

| # | 条目 | 类别 | 判定依据 |
|---|---|---|---|
| 01 | 发票拍照识别老是认错金额，急用，能不能修一下 | 负面 | 明确表达对识别准确率的不满，「急用」体现焦躁情绪 |
| 02 | Huawei Mate 40 一点发票识别就闪退，卸了重装也没用，一星 | 负面 | 打一星评分，「卸了重装也没用」表达强烈不满 |
| 03 | 记账很顺手，五星，就差多账本功能了 | 正面 | 五星好评，「很顺手」为明确满意表达 |
| 04 | 月报表希望支持导出 Excel，会计要用 | 中性 | 仅陈述功能需求与使用场景，无明显情绪倾向词 |
| 05 | 群里有没有人遇到 Xiaomi 13 打开报表页就退出的？我这边天天如此 | 中性 | 以询问形式陈述故障事实，未见明显情绪词（见存疑项） |
| 06 | 你们再不修闪退我就换随手记了，用了两年真的寒心 | 负面 | 明确流失意向（换竞品）+「寒心」表达失望情绪 |
| 07 | 新版界面挺清爽的，报表导出功能要是能上线就完美了 | 正面 | 「挺清爽」为肯定表达，整体语气积极 |
| 08 | 发票识别不准 + 闪退，这版本没法用 | 负面 | 「没法用」为对当前版本的明确否定 |

## 分布统计

| 类别 | 数量 | 占比 |
|---|---|---|
| 负面 | 4 | 50% |
| 正面 | 2 | 25% |
| 中性 | 2 | 25% |

## 存疑项

1. 条目 05：表述为故障求助式询问，「天天如此」隐含不满，可争议归为负面；因缺少明确情绪词，本次按中性处理。
2. 条目 03：整体为正面，但「就差多账本功能了」附带轻度期待落空的意味，若采用更细的分类体系可拆为「正面+功能诉求」复合标签。

—— AI 生成内容，需人工复核 ——


```
