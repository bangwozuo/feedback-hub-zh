# 需求强度打分

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_dev_04_sk04` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 反馈分析师 |
| 能力族 | — |
| 复杂度 | `S` |
| 阶段 | `P1` |
| 复用度 | 中 |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

按频次×付费意愿×流失风险打分

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `records` | string | ✅ | 打分对象的数据记录 |

## 输出规格

打分与分层

- `scores`：逐条给出各维度分与总分
- `segments`：各层数量与特征
- `assumption`：所用维度、权重与阈值的来源或假设

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` |
| **ChatGPT** | 新建 GPT → Instructions → 粘贴 `prompt.txt` |

## 边界（不做的事）

- ❌ 编造数据、案例或效果承诺
- ❌ 使用违反《广告法》的极限词
- ❌ 生成诱导好评、刷量、删差评等违规内容
- ❌ 执行或建议任何绕过平台规则的操作
- ❌ 涉及资金操作或代替用户做最终决策
- ❌ 处理超出本职能力范围的请求（应明确说明并建议转其他技能）

## 调用示例

**输入**：

```json
{
  "records": "R01 发票拍照自动识别金额与抬头：近30天被提及 47 次，18 位用户表示愿意为该功能付费（问卷报价 9.9 元/月时有 12 人明确接受）；有 5 位用户称识别不准就卸载换用随手记。R02 多账本切换：近30天被提及 26 次，8 位用户表示愿意付费；暂无流失表态。R03 月度经营报表导出 Excel：近30天被提及 15 次，11 位用户表示愿意付费（多为年营业额 50 万以上的个体户）；2 位用户称不导出就不续费会员。R04 深色模式：近30天被提及 22 次，3 位用户表示愿意付费；1 位用户称长期不做就换其他记账应用。",
  "dimensions": "频次（占40%）、付费意愿（占35%）、流失风险（占25%），各维度按 1-10 分打分后加权求和",
  "thresholds": "总分 ≥8.0 为 S 级（本迭代优先做），6.0-7.9 为 A 级（排期做），4.0-5.9 为 B 级（观察），<4.0 为 C 级（暂缓）"
}

```

**输出**：

```markdown
# 需求强度打分 — 执行输出

## 评分明细

| # | 对象 | 维度A | 维度B | 总分 | 分层 |
|---|---|---|---|---|---|
| R01 | 发票拍照自动识别金额与抬头 | 频次 10（47次） | 付费意愿 6（18/60 人愿付） / 流失风险 8（5 人明确流失表态） | 8.1 | S 级 |
| R02 | 多账本切换 | 频次 6（26次） | 付费意愿 4（8/60 人愿付） / 流失风险 2（无流失表态） | 4.3 | B 级 |
| R03 | 月度经营报表导出 Excel | 频次 4（15次） | 付费意愿 5（11/60 人愿付） / 流失风险 6（2 位会员称不导出不续费） | 4.9 | B 级 |
| R04 | 深色模式 | 频次 5（22次） | 付费意愿 3（3/60 人愿付） / 流失风险 4（1 人称长期不做就换应用） | 4.1 | B 级 |

注：总分 = 频次×40% + 付费意愿×35% + 流失风险×25%，各维度按 1-10 分打分；维度A 为频次，维度B 内含付费意愿与流失风险两项分值。

## 分层汇总

| 层级 | 数量 | 占比 | 典型特征 | 建议动作 |
|---|---|---|---|---|
| S 级（≥8.0） | 1 | 25% | 提及频次最高，存在明确流失表态，付费意愿中等 | 本迭代优先做 |
| A 级（6.0-7.9） | 0 | 0% | 无 | 无 |
| B 级（4.0-5.9） | 3 | 75% | 频次中等，付费意愿或流失风险单项突出 | 排期做 |
| C 级（<4.0） | 0 | 0% | 无 | 无 |

## 假设说明

1. 维度与权重采用输入指定口径：频次 40%、付费意愿 35%、流失风险 25%，各维度按 1-10 分打分后加权求和。
2. 频次得分按 30 天提及次数相对映射（47 次记 10 分，其余按比例就近取整）；付费意愿得分按问卷中明确接受付费的人数占比映射；流失风险得分按明确流失表态的人数与强度映射。
3. 分层阈值采用输入指定口径：≥8.0 为 S 级、6.0-7.9 为 A 级、4.0-5.9 为 B 级、<4.0 为 C 级；阈值为用户给定假设，不代表唯一正解，结果供排序参考。

—— AI 生成内容，需人工复核 ——


```
