# 更新日志生成

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_dev_04_sk06` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 反馈分析师 |
| 能力族 | — |
| 复杂度 | `S` |
| 阶段 | `P2` |
| 复用度 | 高（副产品，单卖都值） |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

根据产品主体信息（产品名、版本号、发布日期）与已上线需求/修复清单，起草条款化、分条编号的更新日志（changelog）草稿：每条变更标注【新增】/【优化】/【修复】类型前缀、以用户视角描述（单条 20-60 字）、附变更明细表（类型/内容/受影响范围），并列出待补充信息与三层复核提示（产品核对、法务合规复核、不构成效果承诺）。适用于应用市场更新说明、官网 Release Notes、群公告等发布场景。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `subject` | string | ✅ | 适用于谁、什么产品/主体 |

## 输出规格

制度与协议文本

- `document`：条款化、分条编号的完整文本
- `placeholder`：需要用户补充的具体信息（公司名、联系方式等）
- `disclaimer`：需法务或专业机构复核的说明

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` |
| **ChatGPT** | 新建 GPT → Instructions → 粘贴 `prompt.txt` |

## 边界（不做的事）

- ❌ 编造数据、案例或效果承诺
- ❌ 使用违反《广告法》的极限词
- ❌ 生成诱导好评、刷量、删差评等违规内容
- ❌ 执行或建议任何绕过平台规则的操作
- ❌ 涉及资金操作或代替用户做最终决策
- ❌ 处理超出本职能力范围的请求（应明确说明并建议转其他技能）

## 调用示例

**输入**：

```json
{
  "subject": "云记账 App（面向个体工商户的记账工具），版本 v2.6.0，发布日期 2026-09-30",
  "scope": "本次更新需覆盖以下已上线需求：1) 发票拍照自动识别金额与抬头；2) 多账本切换；3) 月度经营报表导出 Excel；4) 修复安卓端部分机型闪退问题（涉及 Huawei Mate 40、Xiaomi 13）"
}

```

**输出**：

```markdown
# 更新日志生成 — 执行输出

## 文本正文

**云记账 App v2.6.0 更新日志（发布日期：2026-09-30）**

1. 【新增】发票拍照自动识别功能上线，可自动识别发票金额与抬头信息，减少手工录入。
2. 【新增】支持多账本切换，可分别管理不同主体的账目（如店铺账与家庭账）。
3. 【新增】月度经营报表支持导出为 Excel 文件，便于交由会计或财务人员查看。
4. 【修复】修复安卓端部分机型在特定页面发生闪退的问题，涉及机型包括 Huawei Mate 40、Xiaomi 13。

—— AI 生成内容，发布前需人工确认 ——

## 待填项

1. 开发者/公司主体名称（用于更新日志署名与联系信息）
2. 用户反馈或问题咨询的联系方式（如客服邮箱、官网地址）
3. 本次更新覆盖的完整机型清单（如需精确列出全部修复机型）

## 复核提示

本更新日志由 AI 依据提供的已上线需求信息起草，仅作草稿使用。对外发布前须由产品负责人核对功能描述与实际实现一致，并由法务或合规人员复核是否存在宣传表述风险；日志不构成任何功能效果承诺。


```
