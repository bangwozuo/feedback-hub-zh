### 示例 2：反馈聚类

**能力**：语义去重与主题聚类

**输入**：

```json
{
  "items": [
    {
      "标题": "新品上线",
      "平台": "X"
    },
    {
      "标题": "功能更新",
      "平台": "Reddit"
    }
  ]
}
```

**输出**：

## 要点摘要

开发者在冷启动期最缺的不是执行力，而是「在哪个渠道、对谁、说什么」的判断依据。

## 痛点清单

1. **选题无依据** — 凭感觉发内容，不知道哪条会有效（来源 1、3）
2. **渠道分散** — 同时维护 5 个平台，每个都做不深（来源 2）

## 情绪倾向

偏负面 — 多数帖子在描述「投入多但反馈少」的挫败感

## 证据索引

- 来源 1：日更 30 天，仅 2 条内容带来有效转化
- 来源 2：5 个平台来回切，最后都荒废

**资产位置**：`skills/feedback-cluster/`

### 示例 5：周报生成

**能力**：反馈数据汇总为决策周报

**输入**：

```json
{
  "metrics": {
    "流水": 4860,
    "客流": 128,
    "差评数": 0
  }
}
```

**输出**：

## 一句话结论

今天生意比昨天好，但晚市时段客流下滑 18%。

## 关键指标

| 指标 | 今日 | 昨日 | 变化 |
|------|------|------|------|
| 流水 | ¥4,860 | ¥4,320 | ↑ 12.5% |
| 客流 | 128 | 119 | ↑ 7.6% |
| 差评数 | 0 | 0 | — |

## 异常预警

**有** — 晚市 19:00-21:00 客流仅 32 人，显著低于该时段均值（52 人）

## 行动建议

1. 检查今晚周边是否有活动分流（商场促销 / 社区活动）
2. 若连续 3 天晚市低于均值，考虑调整晚市套餐结构
3. 明天关注同一时段，确认是偶发还是趋势

**资产位置**：`skills/weekly-report-generate/`
